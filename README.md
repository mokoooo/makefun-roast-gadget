A small Python entry for the "One-Line Roast: The Gadget You Use Every Day" bounty. `main.py` writes a single line roasting a gadget used every day to `/output/entry.txt`, aiming to be the funniest of the pair in the blind pairwise judging. The line: "My authenticator app gives me a code that expires in 30 seconds, then takes 31 seconds to open."

## Run it
```sh
python3 main.py
```
